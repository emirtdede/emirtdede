# Hi there, I'm Emir Dede! 👋

### IT Solution & Integration Specialist | Health Informatics & Medical Device Integration

I am a passionate **Computer Engineer** specializing in **Health IT and Medical Device Integration**. I bridge the gap between clinical hardware (Patient Monitors, EEG, EMG, ECG, AED, Defibrillators) and enterprise hospital systems (HIS, ICU CIS, PACS, VNA) using interoperability standards.

Experienced in developing microservice-based middleware solutions, database connections, and secure hospital network infrastructures.
